# auto-motion — 유튜브 롱폼 자동화 파이프라인 해부

사람은 **기획 · 최종 시사 · 발행 승인** 세 곳만 개입하고, 나머지는 저장소 안의 스크립트가 만드는
유튜브 롱폼 자동화 파이프라인의 전체 구조를 공개한 문서입니다.

**문서 보기 → https://kimyoungil21.github.io/auto-motion-pipeline/**

## 담긴 내용

- **E2E 파이프라인 21단계** — 각 단계의 도구·실제 실행 명령·산출물
- **에셋 인벤토리** — 영상 컷 129개, BGM 236곡, SFX, 컴포지션 95종
- **품질 게이트** — preflight / 페이싱 규칙 / 전달 규격 하드 게이트 / 2-pass 라우드니스
- **실측 데이터** — 편당 한계원가 ₩334 ~ ₩9,851, 렌더 시간, 발행 시각 실측
- **8GB RAM** 안에서 5~6분 롱폼을 렌더하는 방법
- **삽질 기록 18건** — 컨테이너·타임스탬프, 생성 모델 한계, 브라우저 자동화, 검수
- **아직 안 된 것** — 구멍도 같이 적었습니다

문서의 모든 숫자는 저장소 안의 파일에서 나온 실측값이고, 확인하지 못한 값은 추정으로 채우지 않고 비워 두었습니다.

## 참고
